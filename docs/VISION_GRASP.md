# 视觉识别抓取方案 - RoboMaster 2026

## 一、环境挑战分析

### 1.1 光照条件
- **红蓝LED强光**: 620nm (红) / 450nm (蓝)
- **亮度变化**: 10-10000 lux
- **频闪干扰**: LED PWM调光

### 1.2 目标物体
- **形状**: 哑铃状，水壶大小
- **数据源**: 带颜色的 STEP 文件
- **需求**: 6DoF 位姿用于精确抓取

## 二、硬件方案分析

### 2.1 相机选型对比

| 方案 | 型号 | 优势 | 劣势 | 推荐度 |
|------|------|------|------|--------|
| 工业相机 | 海康MV-CE060 | 全局快门,抗频闪,高帧率 | 无深度 | ⭐⭐⭐ |
| RealSense | D435i | RGB-D一体,开箱即用 | 850nm红外受红蓝干扰 | ⭐⭐ |
| 双目 | OAK-D | 结构光+RGB+NPU | 红外干扰,价格高 | ⭐⭐ |

**推荐方案**: 工业相机 + 940nm结构光 (避开红蓝LED波长)

### 2.2 抗干扰硬件方案
1. **窄带滤光片** (940nm): 只让近红外通过，屏蔽可见光
2. **主动光源** (940nm LED): 提供稳定光照
3. **全局快门**: 消除运动模糊和LED频闪条纹

### 2.3 Eye-in-Hand 安装
- 相机固定在 link6 末端
- 手眼标定: easy_handeye2 (AX=XB 问题)
- 需添加 camera_link 到 URDF

### 2.4 推荐采购清单
| 设备 | 型号 | 价格 | 用途 |
|------|------|------|------|
| 工业相机 | 海康MV-CE060-10UC | ¥1500 | RGB图像 |

## 三、软件方案分析

### 3.1 合成数据生成 (RTX 40)

**流程**: STEP → Blender/Isaac Sim → 渲染数据集

```
STEP文件 → Blender导入 → 材质/纹理应用
                ↓
        域随机化配置:
        - 光照: HDR环境光 + 点光源随机
        - 背景: 随机纹理/颜色
        - 遮挡: 随机干扰物体
        - 噪声: 高斯/椒盐
                ↓
        渲染 10000+ 张图像
                ↓
        自动生成标注 (bbox + 6DoF位姿)
```

### 3.2 检测模型对比

| 方案 | 模型 | 推理速度 | 精度 | 部署难度 |
|------|------|----------|------|----------|
| 2D检测 | YOLOv8n | 5ms | 高 | 简单(ONNX) |
| 6DoF | FoundationPose | 50ms | 极高 | 中等(TensorRT) |
| 关键点 | CenterPose | 20ms | 中高 | 中等(ONNX) |

**推荐路线**:
1. YOLOv8 快速定位 ROI
2. FoundationPose/ICP 精确6DoF位姿

### 3.3 位姿估计方案

**方案A**: 2D检测 + 深度图 + ICP配准
- 优势: 精度高，利用CAD模型
- 劣势: 需要好的初始位姿

**方案B**: 直接6DoF网络 (FoundationPose)
- 优势: 端到端，泛化性好
- 劣势: 推理较慢

**方案C**: 关键点检测 + PnP
- 优势: 轻量，速度快
- 劣势: 需要人工标注关键点

## 四、技术要点辩论

### 4.1 Sim-to-Real Gap

**问题**: 合成数据训练的模型在真实环境表现下降

| 方法 | 原理 | 效果 |
|------|------|------|
| 域随机化(DR) | 训练时随机光照/背景/噪声 | ⭐⭐⭐ |
| 域适应(DA) | 无监督对齐特征分布 | ⭐⭐ |
| 少量微调 | 采集100张真实图像微调 | ⭐⭐⭐ |

**推荐**: 域随机化 + 少量真实数据微调

### 4.2 颜色特征 vs 几何特征

| 特征类型 | 优势 | 劣势 |
|----------|------|------|
| 颜色 | 区分度高，计算快 | 光照敏感，红蓝干扰 |
| 几何 | 光照不敏感 | 需深度，计算复杂 |

**结论**: 主用几何特征，颜色作辅助验证

### 4.3 工业相机 vs RealSense

| 维度 | 工业相机 | RealSense D435i |
|------|----------|-----------------|
| 快门 | 全局快门 ✅ | 卷帘快门 |
| 帧率 | 100+ fps ✅ | 30 fps |
| 抗频闪 | 强 ✅ | 弱 |
| 深度 | 无 | 有 (850nm红外) |
| 红蓝干扰 | 可滤除 ✅ | 严重受影响 |

**结论**: 工业相机 + 940nm结构光 (避开RealSense的850nm)

## 五、实施路线

### Phase 1: 合成数据 (1周)
1. STEP → Blender 导入，配置材质
2. 编写域随机化脚本
3. 渲染 10000 张图像
4. 自动生成 COCO/YOLO 格式标注

### Phase 2: 模型训练 (1周)
1. YOLOv8 检测训练 (RTX 40)
2. 6DoF 位姿模型训练/微调
3. 导出 ONNX/TensorRT

### Phase 3: 硬件集成 (1周)
1. 相机驱动节点 (海康MVS SDK)
2. 手眼标定 (easy_handeye2)
3. 深度获取验证

### Phase 4: 系统集成 (1周)
1. 检测 → 位姿 → MoveIt 规划
2. 抓取策略 (approach → grasp → retreat)
3. 端到端测试

## 六、ROS2 节点设计

```
camera_driver_node (30Hz)
  └─ 发布: /camera/image_raw, /camera/depth

object_detection_node (30Hz)
  ├─ 订阅: /camera/image_raw
  └─ 发布: /detections (bbox + class)

pose_estimation_node (10Hz)
  ├─ 订阅: /detections, /camera/depth
  └─ 发布: /target_pose (geometry_msgs/PoseStamped)

grasp_planner_node
  ├─ 订阅: /target_pose
  └─ 调用: MoveIt planning service
```
