# 毕业论文上下文

## 基本要求

- **题目**: 基于六轴机械臂和麦轮底盘的视觉伺服物流机器人
- **字数**: 不少于10000字
- **文献**: 15篇以上参考文献
- **格式**: 南方科技大学本科毕业设计论文格式

## 创新点提炼

1. **运动学创新**: 6DOF位姿解耦方案，将问题分解为3+3维，计算效率提升
2. **控制创新**: 动力学前馈+级联PID混合控制，结合Kalman滤波
3. **架构创新**: STM32+ROS2分层架构，实现仿真/真机无缝切换
4. **工程创新**: 模板化FSM框架，多协议电机统一驱动
