### 第三部分：进展汇报（P7-P17，约4分钟）★重点

#### 3A. STM32嵌入式系统（P7-P9）

**P7 - 嵌入式-运动学算法**
- 6DOF位姿解耦方案：前3关节解析法解位置IK(<50μs)、后3关节矩阵法解姿态IK
- D-H坐标系图 + 1-2个关键公式
- 素材：**D-H坐标系图**（🎨2）

**P8 - 嵌入式-状态机与控制**
- 模板化FSM框架图（7个状态及转换）：
  1. ArmHandwithgesture - 手动遥控
  2. ArmRelaxLearning - 松弛学习
  3. ArmResetWrist - 腕部复位
  4. ArmAutoMove - 自动单关节运动
  5. ArmAutoPosition - 自动位姿规划(6DOF IK)
  6. ArmTargetMove - 目标点运动
  7. ArmEscape - 紧急复位
- 1ms实时控制主循环
- 多协议电机统一驱动（DJI/DM/LK）
- 素材：**FSM状态转换图**（🎨3）

**P9 - 嵌入式-通信与集成**
- Seasky协议帧结构：[SOF(0xA5)][Len(2)][CRC8][CmdID][Flags][Payload][CRC16]
- CAN总线拓扑
- 板间通信架构
- 素材：**通信协议帧格式图**（🎨6）

#### 3B. ROS2上位机系统（P10-P15）

**P10 - ROS2节点拓扑**
- 完整节点图：MoveIt2→torque_controller→mujoco/hardware
- 话题/服务连接关系
- 标注频率(200Hz)
- 素材：**ROS2节点拓扑图**（🎨5）

**P11 - 控制算法-动力学前馈**
- 控制律公式：τ = [M(q)q̈ + C(q,q̇) + G(q)] + τ_fb
- KDL库计算M/C/G矩阵
- 计算时间 <1ms @ 200Hz

**P12 - 控制算法-级联PID**
- 级联结构框图：外环P(位置→速度) → 内环PI(速度→力矩)
- 抗积分饱和策略：条件积分(误差<0.1rad时积分) + 积分限幅 + 紧急重置
- 各关节参数表（Kp_pos / Kp_vel / Ki_vel）
- 素材：**级联PID结构框图**（🎨4）

**P13 - 状态估计-Kalman滤波**
- 状态方程：x = [q, q̇]^T
- 预测+更新双步骤
- Q/R参数调优效果对比
- 素材：**滤波前后速度对比曲线截图**（🖥4）

**P14 - MuJoCo仿真与数字孪生**
- 双模式：物理仿真模式 / 数字孪生模式(visualization_only)
- ImGui/ImPlot实时遥测叠加显示
- 素材：**MuJoCo仿真界面截图**（🖥1）

**P15 - 应用层-轨迹管理与任务执行**
- trajectory_manager YAML持久化（保存/加载/执行）
- mission_executor ncurses TUI交互
- cartesian_controller Pilz LIN/PTP规划器
- 素材：**TUI界面截图**（🖥5）+ **笛卡尔控制演示截图**
