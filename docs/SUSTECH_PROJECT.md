一、中期答辩
    毕设中期答辩系里统一组织，要求如下：
1、时间地点：2026年3月5日14:30-17:00举行，地点为三教。具体安排下学期初通知。
2、汇报时长：每位同学10分钟，7分钟介绍+3分钟问答，请不要超时，现场会计时。
3、汇报的内容包括但不仅限于：1）背景介绍与研究目标（简短）；2）研究内容，任务计划；3）进展汇报 （详细）；4）遇到的问题（如有）。需要制作PPT，内容请在汇报前通过指导老师审核。

二、中期自查表
1、中期检查报告提交办法如下：
学生登录本科生毕业论文（设计）管理系统，在中期检查模块填写—保存导出，线下找导师审核签字—学生提交中期检查（导师签名版）至系统。签字版原件请自行保留，后续和其他材料一样统一提交存档。   
2、中期检查报告（包括系统填写信息和系统上传签字版扫描件）的截止时间为2026年3月12日17:00，逾期不提交将按照毕设相关规定执行，每延期一天，毕业论文总成绩扣除1分，请务必注意，按时提交！
3、中期检查报告的填写建议：
（1）个人自述内容包含简要陈述毕业设计（论文）工作进度、完成情况、存在问题及解决方案。此部分格式建议为仿宋、小四、1倍行距；英文和数字需用Times New Roman。若有小标题，则应采用仿宋、四号、加粗字体。
*若论文的撰写语言为英文，则题目简介应全篇用英文撰写。表头内容除论文题目外，仍保留用中文填写。
（2）末尾处需有学生本人手写版签名及落款日期。
（3）指导老师意见建议对开题内容作将要评论，不仅仅只有含“同意”二字。落款日期需补充完整。
（4）中期自查表内容建议不少于2面（page）。纸质版正反双面打印。
