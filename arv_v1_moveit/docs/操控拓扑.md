# Engineer 2026 ARV 操控拓扑

## 拨杆层（最高优先级）

```
左拨杆 DOWN ── 任何时刻、任何右拨杆位置 ──→ 臂 Relax + 底盘 Stop（零力矩）
                这是唯一的急停，不需要键盘急停
```

### 左 MID = 臂操控区

| 右拨杆 | 臂状态 | 说明 |
|--------|--------|------|
| MID | **HostControl** | 上位机力矩透传，取矿自动化 |
| UP | **HostControl** | 同上（不再区分 RcControl） |
| DOWN | **Relax** | 零力矩，可手拖 |

> **变更**: 取消 RcControl 模式。右拨杆 MID/UP 均为 HostControl，简化操作。
> 手动调姿改为上位机 FREEDRIVE 模式（G(q) 补偿下手拖）。

### 左 UP = 底盘操控区 / SDC

| 右拨杆 | 状态 |
|--------|------|
| MID | UpStairs |
| UP | OnlyLeg |
| DOWN | NormalControl |

臂状态：
- **SDCControl** — 由裁判系统自定义控制器驱动关节位置

## 键盘映射

### 全局（任何模式生效）

| 键 | 动作 | TaskCmd |
|----|------|---------|
| X | Escape 复位 — 回安全收缩姿态 | `RESET_HOME(0x02)` |
| G | 夹爪开合切换（独立于轨迹） | `GRIPPER_CMD(0x40)` |

### HostControl 模式（取矿自动化）

#### 矿位选择 — 六边形空间映射

```
        W (矿0, 12点)
  Q (矿5, 10点)   E (矿1, 2点)
  A (矿4, 8点)    D (矿2, 4点)
        S (矿3, 6点)
```

#### 完整键位表

| 键 | 动作 | TaskCmd |
|----|------|---------|
| W | 取矿 0（上） | `PICK_OBJ(0)` 0x10 param=0 |
| E | 取矿 1（右上） | `PICK_OBJ(1)` 0x10 param=1 |
| D | 取矿 2（右下） | `PICK_OBJ(2)` 0x10 param=2 |
| S | 取矿 3（下） | `PICK_OBJ(3)` 0x10 param=3 |
| A | 取矿 4（左下） | `PICK_OBJ(4)` 0x10 param=4 |
| Q | 取矿 5（左上） | `PICK_OBJ(5)` 0x10 param=5 |
| **Z** | **存矿到身上左槽** | `STOW_LEFT` 0x24 |
| **C** | **存矿到身上右槽** | `STOW_RIGHT` 0x25 |
| **Shift+Z** | **从身上左槽取矿** | `RETRIEVE_LEFT` 0x26 |
| **Shift+C** | **从身上右槽取矿** | `RETRIEVE_RIGHT` 0x27 |
| B | **任意时刻 fast-forward**（详见下） | `NEXT_STEP` 0x30 |
| F | 中止任务，保持当前位置 | `ABORT_TASK` 0x31 |

> **R 键已废弃**（旧 `STOW_OBJ(auto-slot)` 不再使用，由 Z/C 领域划分替代）。
> Shift 不参与 Key_lock 释放判定，仅作为 Z/C 修饰键读取。

#### Key_lock 机制（防多键）

采用 2025 验证过的全局键锁方案：

- 任何 HostControl 命令键（WASDQE/B/F/Z/C）触发一次命令后，设置 `Key_lock = true`
- `Key_lock = true` 期间，所有 HostControl 命令键被屏蔽
- 只有当 **所有** 命令键（W/A/S/D/Q/E/B/F/Z/C）全部松开时，`Key_lock` 才释放
- 全局键（X/G）和 Shift 修饰键不受 Key_lock 影响

效果：即使多键同时按下，也只会发出一个命令，且必须全松开后才能再按。

### SDC 模式（兑矿）

键盘由裁判系统自定义控制器协议定义。仅 X（Escape）和 G（夹爪）作为全局 fallback。

### 底盘

纯摇杆，键盘不参与底盘控制。

## 任务序列（按键 → 轨迹绑定）

上位机 `config/key_bindings.yaml` 把每个键映射为多步轨迹序列，
`mission_executor_node` 按序执行，state 间用 B 推进。

| 键 | 轨迹序列 | 段间停顿 |
|---|---|---|
| W/A/S/D/Q/E | `cap_{0..5}_1` → 等 B → `cap_{0..5}_2` | step1 末尾停顿等操作手按 B 确认夹取 |
| Z | `save_left_111` → `save_left_safe_exit` | 自动衔接（safe_exit 待录） |
| C | `save_right_111` → `save_right_safe_exit` | 同上 |
| Shift+Z | `pick_s_left_111` → 等 B → `pick_left_1111` | step1 末尾停顿等夹取 |
| Shift+C | `pick_s_right_111` → 等 B → `pick_right_111` | 同上 |

### B 键：任意时刻 fast-forward

- **跑轨迹中按 B** → 调 `/cancel_current_trajectory` 砍当前 FJT goal → LoadTrajectory 返回 canceled → 进下一步
- **awaiting_next 等待状态按 B** → notify CV → 进下一步
- **无 active task 按 B** → DEBUG 忽略

> 旧拓扑 "定时器/B 推进" 已变更：**无定时器，仅 B 推进**。step 跑完后 wait_for_next=true 严格阻塞等 B（"高精度对准"语义）。

### 打断白名单

每个绑定有 `interruptible_by` 列表：进行中只接受白名单内的 cmd，其他丢弃 + WARN：

- **pick_obj_***: 接受 ESTOP / X / B / Z / C（取矿可被存矿打断切换）
- **stow_left/right**: 接受 ESTOP / X / B
- **retrieve_left/right**: 接受 ESTOP / X / B

### 夹爪与轨迹解耦

- 轨迹 yaml 内 `meta.gripper_actions` 段（定时夹/松），LoadTrajectory 返回后由 mission_executor wall-clock 调度
- G 键独立控制，任何时刻可按，立即生效
- G 键优先级 > 轨迹定时 action
- 当前已拼接 gripper：cap_*_2 开头 close、save_*_111 末尾 open、pick_s_* 末尾 close

## 状态转换图

```
                         左拨杆 DOWN
                    （最高优先级 fallback）
                              │
                              v
┌─────────┐   L=MID,R=DOWN  ┌─────────┐
│HostCtrl │ ←──────────────→ │  Relax  │ ←── 左拨杆 DOWN（从任何状态）
│(取矿)   │   L=MID,R=MID/UP │ (安全)  │
└────┬────┘                  └────┬────┘
     │                            │
     │ L=UP                       │ X 键
     v                            v
┌─────────┐                 ┌──────────┐
│   SDC   │                 │Escape姿态│ → ARMED → escape trajectory
│(兑矿)   │                 │(上位机执行)│
└─────────┘                 └──────────┘
```

## 模式切换通知（MCU → PC）

| 事件 | MCU 发送 | PC 响应 |
|------|----------|---------|
| 进入 HostControl | `SET_CONTROL_MODE(ARMED)` | 开始发力矩，进入 hold 模式 |
| 退出 HostControl | `SET_CONTROL_MODE(RELAX)` | 停止发力矩，abort 轨迹 |
| 进入 Relax | (由退出 Host 覆盖) | 零力矩 |

## Edge Case

### 1. 拨杆快速切换

DR16 三档开关是离散的，不存在连续过渡。状态机只在精确匹配时触发。

### 2. 取矿中途拨杆切 Relax

左拨下 → 立即零力矩 → MCU 发送 `SET_CONTROL_MODE(RELAX)` → 上位机自动 ABORT 当前任务。恢复后需重新选矿。

### 3. 取矿中途按 X

中止当前轨迹 → 规划 Escape 姿态 → 执行。上位机 RESET_HOME 处理中先 ABORT 再 load escape trajectory。

### 4. 同时按多个矿位键

Key_lock 机制保证只发第一个检测到的键。必须全部松开后才能触发下一个命令。

### 5. 按 B 但没选矿

没有 active task 时 NEXT_STEP 被上位机忽略。

### 6. 拔出完成后不按 R

臂保持 ARMED + HOLDING（G(q) + PD hold）。无超时，操作手任意时刻按 R 存矿。

### 7. 存矿 slot 满

3 个 slot 全占 → R 被拒绝 → WARN log → 臂保持 HOLDING。需先兑矿释放 slot。

### 8. 夹爪手动覆盖

G 键立即执行，优先级高于轨迹定时 action。后续定时 action 到达时若状态已一致则无操作。

### 9. HostControl 快速 Relax→HostControl

拨杆 R=DOWN 再回 R=MID:
- MCU 先发 RELAX → PC abort + 零力矩
- MCU 再发 ARMED → PC 恢复 hold（锁定当前反馈位置为目标）
- Key_lock + ResetKeyLocks 保证无幽灵命令

### 10. SDC 模式夹爪

SDC 模式下 Q 键直接控制夹爪（MCU 本地 SetPosition），不经过上位机。
G 键（全局）仍可用，但通过 0x0005 走上位机路径，效果可能与 SDC Q 冲突。
规则：SDC 下用 Q，不用 G。
