# Engineer 2026 ARV 操控拓扑

## 拨杆层（最高优先级）

```
左拨杆 DOWN ── 任何时刻、任何右拨杆位置 ──→ 臂 Relax + 底盘 Stop（零力矩）
                这是唯一的急停，不需要键盘急停
```

### 左 MID = 臂操控区

| 右拨杆 | 臂状态 | 说明 |
|--------|--------|------|
| MID | **HostControl** | 上位机力矩透传，取矿自动化 |
| UP | **HostControl** | 同上（不再区分 RcControl） |
| DOWN | **Relax** | 零力矩，可手拖 |

> **变更**: 取消 RcControl 模式。右拨杆 MID/UP 均为 HostControl，简化操作。
> 手动调姿改为上位机 FREEDRIVE 模式（G(q) 补偿下手拖）。

### 左 UP = 底盘操控区 / SDC

| 右拨杆 | 状态 |
|--------|------|
| MID | UpStairs |
| UP | OnlyLeg |
| DOWN | NormalControl |

臂状态：
- **SDCControl** — 由裁判系统自定义控制器驱动关节位置

## 键盘映射

### 全局（任何模式生效）

| 键 | 动作 | TaskCmd |
|----|------|---------|
| X | Escape 复位 — 回安全收缩姿态 | `RESET_HOME(0x02)` |
| G | 夹爪开合切换（独立于轨迹） | `GRIPPER_CMD(0x40)` |

### HostControl 模式（取矿自动化）

#### 矿位选择 — 六边形空间映射

```
        W (矿0, 12点)
  Q (矿5, 10点)   E (矿1, 2点)
  A (矿4, 8点)    D (矿2, 4点)
        S (矿3, 6点)
```

| 键 | 动作 | TaskCmd |
|----|------|---------|
| W | 取矿 0（上） | `PICK_OBJ(0)` |
| E | 取矿 1（右上） | `PICK_OBJ(1)` |
| D | 取矿 2（右下） | `PICK_OBJ(2)` |
| S | 取矿 3（下） | `PICK_OBJ(3)` |
| A | 取矿 4（左下） | `PICK_OBJ(4)` |
| Q | 取矿 5（左上） | `PICK_OBJ(5)` |
| B | 推进下一步（定时器到也自动推进，B 可快进） | `NEXT_STEP(0x30)` |
| F | 中止任务，保持当前位置 | `ABORT_TASK(0x31)` |
| R | 存矿（自动选下一个空 slot，最多 3 个） | `STOW_OBJ(auto)` |

#### Key_lock 机制（防多键）

采用 2025 验证过的全局键锁方案：

- 任何 HostControl 命令键（WASDQE/B/F/R）触发一次命令后，设置 `Key_lock = true`
- `Key_lock = true` 期间，所有 HostControl 命令键被屏蔽
- 只有当 **所有** 命令键（W/A/S/D/Q/E/B/F/R）全部松开时，`Key_lock` 才释放
- 全局键（X/G）不受 Key_lock 影响

效果：即使多键同时按下，也只会发出一个命令，且必须全松开后才能再按。

### SDC 模式（兑矿）

键盘由裁判系统自定义控制器协议定义。仅 X（Escape）和 G（夹爪）作为全局 fallback。

### 底盘

纯摇杆，键盘不参与底盘控制。

## 取矿流程

```
选矿(WASDQE) → [伸入] --定时器/B-→ [夹住] --定时器/B-→ [拔出] --定时器/B-→ [完成]
                  ↑                                              │
                  ├── F 中止回 idle ─────────────────────────────┘
                  └── X Escape 回安全姿态 ───────────────────────┘

完成后按 R → 存矿（auto-slot 0/1/2）→ 返回 idle，可继续选矿
```

### 夹爪与轨迹解耦

- 轨迹 yaml 内可插入 `gripper_actions`（定时夹/松），自动执行
- G 键独立控制，任何时刻可按，立即生效
- G 键优先级 > 轨迹定时 action

### 存矿容量

- 手中最多携带 3 个矿（slot 0/1/2）
- R 存矿时自动选下一个空位
- 3 个都满时 R 被拒绝
- 兑矿（SDC 模式）取出矿后 slot 释放

## 状态转换图

```
                         左拨杆 DOWN
                    （最高优先级 fallback）
                              │
                              v
┌─────────┐   L=MID,R=DOWN  ┌─────────┐
│HostCtrl │ ←──────────────→ │  Relax  │ ←── 左拨杆 DOWN（从任何状态）
│(取矿)   │   L=MID,R=MID/UP │ (安全)  │
└────┬────┘                  └────┬────┘
     │                            │
     │ L=UP                       │ X 键
     v                            v
┌─────────┐                 ┌──────────┐
│   SDC   │                 │Escape姿态│ → ARMED → escape trajectory
│(兑矿)   │                 │(上位机执行)│
└─────────┘                 └──────────┘
```

## 模式切换通知（MCU → PC）

| 事件 | MCU 发送 | PC 响应 |
|------|----------|---------|
| 进入 HostControl | `SET_CONTROL_MODE(ARMED)` | 开始发力矩，进入 hold 模式 |
| 退出 HostControl | `SET_CONTROL_MODE(RELAX)` | 停止发力矩，abort 轨迹 |
| 进入 Relax | (由退出 Host 覆盖) | 零力矩 |

## Edge Case

### 1. 拨杆快速切换

DR16 三档开关是离散的，不存在连续过渡。状态机只在精确匹配时触发。

### 2. 取矿中途拨杆切 Relax

左拨下 → 立即零力矩 → MCU 发送 `SET_CONTROL_MODE(RELAX)` → 上位机自动 ABORT 当前任务。恢复后需重新选矿。

### 3. 取矿中途按 X

中止当前轨迹 → 规划 Escape 姿态 → 执行。上位机 RESET_HOME 处理中先 ABORT 再 load escape trajectory。

### 4. 同时按多个矿位键

Key_lock 机制保证只发第一个检测到的键。必须全部松开后才能触发下一个命令。

### 5. 按 B 但没选矿

没有 active task 时 NEXT_STEP 被上位机忽略。

### 6. 拔出完成后不按 R

臂保持 ARMED + HOLDING（G(q) + PD hold）。无超时，操作手任意时刻按 R 存矿。

### 7. 存矿 slot 满

3 个 slot 全占 → R 被拒绝 → WARN log → 臂保持 HOLDING。需先兑矿释放 slot。

### 8. 夹爪手动覆盖

G 键立即执行，优先级高于轨迹定时 action。后续定时 action 到达时若状态已一致则无操作。

### 9. HostControl 快速 Relax→HostControl

拨杆 R=DOWN 再回 R=MID:
- MCU 先发 RELAX → PC abort + 零力矩
- MCU 再发 ARMED → PC 恢复 hold（锁定当前反馈位置为目标）
- Key_lock + ResetKeyLocks 保证无幽灵命令

### 10. SDC 模式夹爪

SDC 模式下 Q 键直接控制夹爪（MCU 本地 SetPosition），不经过上位机。
G 键（全局）仍可用，但通过 0x0005 走上位机路径，效果可能与 SDC Q 冲突。
规则：SDC 下用 Q，不用 G。
